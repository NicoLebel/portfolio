Autonomous Robot Embedded Stack

Mission tested embedded C firmware stack designed for an AVR ATmega328P. Features an optical FSK module, dynamic PWM actuator control, Finite State Machine architecture, and ROS2 integration with an onboard Linux companion computer.

Objectives

  • Architect non-blocking, bare-metal C firmware for real-time robotic state control, payload capture, and subsystem management.
  • Implement a UART telemetry link for bidirectional communication between microcontroller peripherals and the onboard ROS2 companion computer.
  • Implement an optical FSK module to transmit data by modulating ASCII binary streams into distinct light frequencies for reliable bit detection.

Outcomes & Contributions

  • Designed and implemented a Finite State Machine (FSM) architecture to ensure non-blocking subsystem execution and seamless system integration.
  • Established interrupt-driven UART communication between the microcontroller and Linux companion computer, bridging telemetry to custom ROS2 topics.
  • Designed an optical FSK modulation algorithm to toggle light transmission frequencies according to system specifications for wireless message transfer.
  • Designed transistor-based switching driver circuits and configured PWM signals for precise actuator control, including servo positioning and electromagnet activation.

Technical Details & Skills

  • Microcontroller Architecture: Bare-metal C development on an AVR ATmega328P utilizing register-level programming.
  • Hardware Peripherals: 16-bit PWM for precise servo actuation, 0.3A electromagnets, and 2N2222 BJT switching drivers configured via GPIO pin mapping.
  • Communication & Sensing: Optical Frequency-Shift Keying (FSK) data transmission via light modulation switching dynamically between 1kHz and 3kHz.
  • System Integration: Linux companion computer bridging via custom ROS2 UART topics, interfacing directly with the microcontroller through UART interrupt service routines (ISRs).
