EV Safety-Critical Firmware

CAN network architecture, FSM deadlock safety, and ECU specifications built for an FSAE Electric vehicle. Features hardware watchdog integration, custom DBC generation, and complete VCU technical documentation to baseline safety requirements and accelerate team onboarding.

Objectives

  • Design a CAN bus network to reliably interconnect the Battery Management System (BMS), High Voltage Controller (HVC), Vehicle Control Unit (VCU), Inverter/Motor Controller, and Driver Display.
  • Enforce fault tolerance and FSAE EV rule compliance by integrating a hardware Independent Watchdog Timer (IWDG) into the VCU Finite State Machine (FSM) to prevent locked-state hazards.
  • Formulate comprehensive system design architectures and operational requirements for major vehicle ECUs (VCU, HVC, BMS).

Outcomes & Contributions

  • Designed custom CAN frame definitions in CANdb++, generating structured database (.dbc) files to easily serialize/deserialize telemetry signals into C abstractions for STM32 microcontrollers.
  • Configured STM32 IWDG peripherals in STM32CubeMX and integrated precise watchdog service routines into execution loops to ensure deterministic state resets during system stalls.
  • Authored detailed system design documentation for the VCU, outlining critical system requirements and establishing technical baselines that streamlined onboarding for junior engineers.

Technical Details & Skills

  • Embedded Firmware: Developed robust, low-level C code to handle real-time vehicle control logic and communication stacks.
  • Communication Protocols: Utilized CAN bus architecture to establish dependable multi-ECU telemetry and data transfer.
  • Hardware & Tooling: Leveraged STM32F407 microcontrollers, STM32CubeMX peripheral configuration, and CANdb++ database generation tools to accelerate development.
  • Safety & Architecture: Implemented safety-critical FSM structures and enforced compliance with strict FSAE electric vehicle regulations during system design.
