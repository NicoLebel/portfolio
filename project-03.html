360° Object Detection System

Embedded C firmware and custom PCB hardware stack designed for an AVR ATmega328P. Features 360-degree ultrasonic detection, custom near-field magnetic coupling wireless data link, FSK modulation algorithm, and tactile touchpad actuator control.

Objectives

  • Design and develop an ultrasonic object detection system featuring a 360-degree field of view intended for autonomous vehicle navigation.
  • Provide high operator flexibility through tactile user inputs via a touchpad, allowing runtime configuration of sensor tilt angles and selectable scanning/spin modes.
  • Minimize the overall physical footprint and weight profile to ensure seamless integration and portability across compact autonomous platforms.

Outcomes & Contributions

  • Designed a custom near-field coupling circuit for wireless data transfer using magnetic fields to bridge rotating top-deck modules with stationary base electronics.
  • Implemented a custom Frequency Shift Keying (FSK) modulation algorithm to convert digital bit streams into analog waveforms for reliable transmission across the wireless link.
  • Designed bidirectional wireless transceiver hardware schematics and implemented layouts on custom printed circuit boards using KiCad.
  • Started the implementation of receiver-side demodulation and bit-detection decoding routines, attempting to establish a framework for robust serial data recovery.

Technical Details & Skills

  • Microcontroller: Bare-metal C development on an AVR ATmega328p utilizing register-level programming.
  • Design Tools: Circuits simulated initially on LTspice, PCB designed and routed using KiCad.
  • Protocols: Custom FSK modulation for Digital-to-Analog conversion of binary information into signals, UART telemetry access for debugging.
  • Hardware Systems: Custom inductor, current amplifier, Hall Effect sensors, ultrasonic sensors, and servo motors were used.
